\# ⚽ FutbolWebApp



Aplicación web desarrollada con \*\*DataFlex\*\* durante mi periodo de prácticas en empresa (Datacontrol), conectada a una base de datos \*\*MySQL\*\*.



\## Estado del proyecto



Proyecto realizado durante mi periodo de prácticas en empresa. Se desarrolló durante esos meses y concluyó al finalizar el periodo formativo.



\## Descripción



Gestión de datos de un club de fútbol (equipos, jugadores, entrenadores, posiciones y ligas) a través de una aplicación web que corre en local, construida con DataFlex y conectada a una base de datos MySQL.



\### Funcionalidades



\- Login de usuario

\- Gestión de equipos, jugadores, entrenadores, posiciones y ligas (alta, edición, consulta)

\- Paneles de selección (Select) y ficha de detalle (Zoom) para cada entidad

\- Conexión con base de datos MySQL mediante ODBC



\### Tecnologías



DataFlex · MySQL · ODBC · HTML/CSS



\## Por qué DataFlex



DataFlex es un lenguaje de alto nivel poco extendido, con muy poca documentación en internet en comparación con lenguajes como Java. Aprenderlo supuso trabajar directamente con el Help oficial del programa en lugar de apoyarme en foros o en una IA, y entender cómo migrar y verificar datos entre DataFlex y MySQL en ambas direcciones.



\## Nota



Este proyecto corre en local y no está publicado en ningún servidor, por lo que no hay una demo disponible; el código de este repositorio es la referencia del trabajo realizado.
